# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Email **info@smilecommunitycentre.org** with the subject "Security report", a description, the affected URL or file, and steps to reproduce. We aim to acknowledge reports within 3 working days and to fix confirmed issues as quickly as possible.

If the issue involves a child's personal information or photo, say so in the subject line so it is routed to the safeguarding lead.

## Supported versions

Only the latest release of the `smile-community-child` theme and the bundled Smile Community Core plugin receives fixes. See [CHANGELOG.md](CHANGELOG.md).

## How the site is protected

A full review of controls, findings and fixes is in [SECURITY-AUDIT.md](SECURITY-AUDIT.md): security headers and HTTPS, rate-limited forms and sign-in, nonce and capability checks, input sanitisation and output escaping, no secrets in code, and photo metadata stripping.
