# Crawler access matrix

Policy owner decision, 11 Nov 2026 (Lightsof): **allow search, user-requested and training crawlers**. Admin (`/wp-admin/`) and internal search results stay closed to every crawler. robots.txt is generated by the theme (`inc/ai-discovery.php`) and overrides Rank Math's robots editor, so the policy lives in this repo.

| Crawler | Operator | Purpose | Rule | Notes |
|---|---|---|---|---|
| Googlebot, Googlebot-Image | Google | Search indexing | Allow | Google Search, AI Overviews |
| Google-Extended | Google | Gemini training/grounding control token | Allow | Not a separate crawler; a robots token |
| Bingbot | Microsoft | Search indexing | Allow | Bing, Copilot; IndexNow via Rank Math Instant Indexing |
| Applebot / Applebot-Extended | Apple | Search / AI training control | Allow | Siri, Spotlight, Apple Intelligence |
| DuckDuckBot | DuckDuckGo | Search | Allow | |
| OAI-SearchBot | OpenAI | ChatGPT search results | Allow | Separate from GPTBot |
| ChatGPT-User | OpenAI | Fetches a page when a user asks | Allow | |
| GPTBot | OpenAI | Model training | Allow | Owner decision; can be switched to Disallow |
| PerplexityBot / Perplexity-User | Perplexity | Search index / user fetch | Allow | |
| Claude-SearchBot / Claude-User / ClaudeBot | Anthropic | Search / user fetch / training | Allow | |
| CCBot | Common Crawl | Open web dataset | Allow | Feeds many AI models |
| * (everyone else) | | | Allow, except /wp-admin/ and ?s= | |

To change a rule, filter `smile_crawler_agents` or edit `smile_robots_txt()`. robots.txt is not access control: private data must be protected by login, not by robots rules. A firewall or host rule can still block a crawler that robots.txt allows; check the host (VivaWebHost) if Search Console or Bing reports blocked fetches.

Also served: `/llms.txt` (plain-text guide to the site for AI tools, verified facts only, `noindex`). It helps AI tools find the right pages; it does not replace robots.txt, sitemaps or canonical tags.
